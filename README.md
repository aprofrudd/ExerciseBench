# ExerciseBench
An expert-moderated benchmark for evaluating AI exercise advice 
**Status:** Pilot study protocol. Data collection not started. 
- [Pilot protocol](protocol.md)
- **Author:** Dr Alan Ruddock

## About 
ExerciseBench is a planned benchmark for evaluating how large language models answer exercise questions, built on HealthBench but with transparent theme development, expert-moderated rubrics and checks of the AI grader against experts. This repository holds the pilot protocol.
